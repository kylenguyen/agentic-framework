# agentic-framework

Source of truth for a headless Ubuntu box on a Tailscale tailnet that runs coding agents (Claude Code,
OpenCode, Oh My Pi), and for the Macs that reach it from WezTerm over SSH or mosh. The examples below call the
host `as1` and its login `kyle`; both are parameters, see the table further down. Two idempotent scripts do all
the configuration; configs on the host are symlinks into this checkout, so edit here, never the installed copy.

| Script | Runs on | As | Does |
|---|---|---|---|
| `install-as1.sh` | host | the host login; `sudo` per command, only for phase 1 steps not yet done | phase 1: sshd hardening, apt packages, zsh as login shell, ufw, linger, Tailscale auto-update; then symlinked configs, secrets file skeleton, `xclip` shim, oh-my-zsh, mise toolchains, uv, the three harnesses |
| `install-mac.sh` | Mac | you, no sudo | mosh, pngpaste, `~/.ssh/config` block, SSH key and key login to the host, WezTerm include, `clip-push` |

Order: host prerequisites, then the Mac script (it puts the Mac key on the host), then the host script, then
one-time logins, then the joint checkpoints. Keep a key-based SSH session open while the host script runs;
its phase 1 reloads sshd.

Conventions: `as1$` is a shell on the host, `mac$` a local shell on the Mac.

### Parameters

No script, template or config carries a host name, address or login. They come from `.env` at the repo root
(gitignored; template `.env.example`; rules in `lib/params.sh`), or from the system on the host:

| Parameter | Meaning | Host (`install-as1.sh`) | Mac (`install-mac.sh`) |
|---|---|---|---|
| `AGENT_HOST` | ssh alias and WezTerm domain name | `hostname -s` | `.env`, required |
| `AGENT_HOST_ADDRESS` | what the Mac connects to | Tailscale MagicDNS name, else `AGENT_HOST` | `.env`, default `AGENT_HOST` |
| `AGENT_HOST_USER` | login on the host: sshd `AllowUsers`, ssh `User` | the login running the script; `.env` must agree | `.env`, required |
| `AGENT_HOST_LAN_IP` | host address on the LAN, for `ssh <alias>-lan` | `src` of the default route | `.env`, optional |
| `AGENT_HOST_LAN_CIDR` | LAN range ufw lets ssh in from | connected route of the default interface; must be RFC 1918 unless set in `.env` | not used |

`.env` values override the derived ones, except the login. The host script writes `.env` on its first run and
prints the lines for the Macs at the end. On a Mac, copy `.env.example` to `.env` and edit it, or let the script
ask. Files that need a parameter are `.in` templates rendered at install time: `config/sshd/10-hardening.conf.in`,
`config/ssh_config.mac.in`, `config/wezterm-agent-host.lua.in`, `bin/clip-push-mac.sh.in`. Not parameters: the Mac
names (`macbook`, `mini`, docs only), the repo URL in the clone commands, the Mac key `~/.ssh/id_ed25519` (no
passphrase, generated by `install-mac.sh` if absent), `~/workspace`, tmux session `main`.

## 1. as1 prerequisites (console, once)

Manual on purpose, so a script re-run can never lock you out.

1. Install Ubuntu Server LTS. Pick the hostname (`as1`) and a login (`kyle`) with a real password, tick "Install
   OpenSSH server". The hostname becomes the ssh alias and the login the only account sshd allows.
   Importing a GitHub SSH identity is optional; it turns password login off until the host script runs,
   so a Mac with a new key must then have its key pasted at the console instead of `ssh-copy-id`.
2. Fixed LAN address `192.168.10.2` (DHCP reservation on the router).
3. Base packages, Tailscale, repo clone:
   ```
   as1$ sudo apt update && sudo apt full-upgrade -y && sudo apt install -y git curl
   as1$ curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up     # open the URL on a signed-in device
   as1$ mkdir -p ~/workspace && git clone https://github.com/kylenguyen/agentic-framework.git ~/workspace/agentic-framework
   ```
   In the Tailscale admin console: MagicDNS on, and "Disable key expiry" for as1. For a private repo,
   `sudo apt install -y gh && gh auth login` before the clone.

Verify:
```
as1$ hostname; systemctl is-active ssh tailscaled           # as1, active, active
as1$ tailscale ip -4                                         # 100.x.y.z
as1$ passwd -S kyle | awk '{print $2}'                       # P (a password is set)
as1$ sudo sshd -T | grep -i ^passwordauthentication          # yes, unless a GitHub key was imported
as1$ ls ~/workspace/agentic-framework/install-as1.sh
```

## 2. Mac client

Prerequisites, manual: FileVault on (the SSH key has no passphrase), Homebrew, WezTerm
(`brew install --cask wezterm`), and the Tailscale app signed in to the same tailnet with
"Start Tailscale on login" ticked and Tailscale DNS on.

```
mac$ mkdir -p ~/workspace && git clone https://github.com/kylenguyen/agentic-framework.git ~/workspace/agentic-framework
mac$ cd ~/workspace/agentic-framework && cp .env.example .env && $EDITOR .env      # alias, address, login, LAN address
mac$ ./install-mac.sh
```

Run it in a terminal, not from a pipe. It prints the parameters it read (with no `.env` it asks for them and
writes the file), installs mosh and pngpaste, writes the `as1`, `as1-lan` and `as1-clip` blocks into
`~/.ssh/config` (the `agentic-framework:agent-host` marker block; no `as1-lan` without a LAN address), generates
`~/.ssh/id_ed25519` if absent, renders and installs the WezTerm include (writes a minimal `wezterm.lua` if you have
none, otherwise adds the one `require("wezterm-agent-host")` line before your `return config`, keeping the original
as `wezterm.lua.before-agent-host`), installs `clip-push`, puts `~/.local/bin` on PATH via `~/.zshrc`, and finally
makes `ssh as1` log in by key with no prompt. On first contact it stores the host key; if the host trusts no local
key it runs `ssh-copy-id` and asks for the host password once. It ends with `ok   ssh as1 logs in by key`.

It exits 1, with the command to run, when: as1 is unreachable (check Tailscale); a stored host key no longer
matches after a reinstall (`ssh-keygen -R as1; ssh-keygen -R 192.168.10.2`); or password login is off and no
key is trusted (paste `~/.ssh/id_ed25519.pub` into `~/.ssh/authorized_keys` on as1 at the console). Fix and re-run.

Then open a new shell and reload WezTerm with Cmd+Shift+R.

Verify (Mac alone):
```
mac$ ssh -G as1 | grep -E '^(hostname|user|identityfile) '                  # as1, kyle, ~/.ssh/id_ed25519
mac$ ssh -G as1-clip | grep -E '^(batchmode|controlmaster|connecttimeout) ' # yes, auto, 3
mac$ /Applications/Tailscale.app/Contents/MacOS/Tailscale status | grep as1 # listed, not offline
mac$ grep -c wezterm-agent-host ~/.config/wezterm/wezterm.lua               # 1
mac$ command -v clip-push && mosh --version | head -1                       # ~/.local/bin/clip-push
mac$ ssh as1 true && echo key-login-ok                                      # no prompt
```

## 3. as1 script

```
mac$ ssh as1
as1$ cd ~/workspace/agentic-framework && ./install-as1.sh        # --no-tools skips network installs, --no-root skips phase 1
```

Run it as the host login (`kyle`), never with `sudo`. It starts by printing the parameters it derived (host name,
Tailscale name, login, LAN address and range) and writes `.env` if there is none; edit `.env` and re-run to
override. Phase 1 runs the root steps one command at a time through `sudo`, each only when the host is not already
in the wanted state, so `sudo` asks for your password once on a fresh host and not at all on a re-run of a
configured one. It refuses to start phase 1 unless the login has a password. It renders
`config/sshd/10-hardening.conf.in` for that login (key or password for that login only, no root, no empty
passwords), installs it when the directives differ from what is installed, and reloads sshd; installs tmux, mosh,
gh, zsh, git, curl, file, jq, unattended-upgrades; sets zsh as the login shell; applies `config/ufw.sh` with the LAN
range (inbound only on `tailscale0`, plus SSH from the LAN; a derived range must be private); enables linger; turns
on Tailscale auto-update and unattended-upgrades.

Phases 2 to 4 run as the login: symlink `~/.tmux.conf`, `~/.zshenv`, `~/.zshrc`, `~/.bashrc.d`, `~/.claude/settings.json`,
`~/.claude/statusline-command.sh`, `~/workspace/CLAUDE.md` and `~/workspace/AGENTS.md` into the repo; create
`~/.config/agents/env` from `secrets.env.example` (mode 600); install the `xclip` shim and `clip-put`; with network,
install oh-my-zsh, mise with Node, Bun and Python 3.12, uv, OpenCode, Oh My Pi and Claude Code. It ends by printing
the `.env` lines for the Macs.

Log out and back in. The new login lands in zsh inside tmux session `main`. If an older `main` session still
runs bash: `tmux kill-server`, log in again.

Verify, from the open session and a new one:
```
as1$ sudo sshd -T | grep -iE '^(passwordauthentication|permitrootlogin|allowusers) '   # yes, no, kyle
as1$ sudo ufw status verbose | grep -E 'Status|tailscale0|192.168.10'
as1$ loginctl show-user kyle | grep Linger                                             # Linger=yes
as1$ getent passwd kyle | cut -d: -f7                                                  # /usr/bin/zsh
mac$ ssh as1 true && echo still-ok
mac$ ssh -o PreferredAuthentications=password -o PubkeyAuthentication=no kyle@as1 true && echo password-ok
as1$ echo $ZSH_THEME $TMUX | cut -c1-40           # robbyrussell /tmp/tmux-...
as1$ for c in mise node bun python3.12 uv claude opencode omp; do printf '%-10s %s\n' $c "$(command -v $c || echo MISSING)"; done
as1$ command -v xclip                             # ~/.local/bin/xclip, not /usr/bin
as1$ stat -c '%a' ~/.config/agents/env            # 600
as1$ readlink ~/workspace/AGENTS.md               # .../config/workspace/CLAUDE.md
as1$ cat ~/workspace/agentic-framework/.env       # the five AGENT_HOST_* lines, same values install-as1.sh printed
as1$ bash ~/workspace/agentic-framework/tests/params-test.sh | tail -1   # N passed, 0 failed
mac$ ssh as1 'echo tmux=$TMUX; command -v mise'   # tmux= (empty), then a mise path
```

## 4. One-time logins and secrets (as1, manual)

Both logins print a URL and a code; open the URL in the Mac's browser.

1. Claude Code: `as1$ claude`, sign in, `/exit`. Or put `ANTHROPIC_API_KEY` in the secrets file; that is what
   `claude --bare` and non-interactive use need.
2. GitHub: `as1$ gh auth login` (GitHub.com, HTTPS, browser). Keep the repo remote on HTTPS.
3. Secrets: `as1$ $EDITOR ~/.config/agents/env`. Sourced by every shell, including `ssh as1 <cmd>`. Claude Code
   is denied read access to it by `config/claude-settings.json`.

Verify:
```
as1$ gh auth status
as1$ claude -p 'reply with the single word ok'
mac$ ssh as1 'claude --bare -p "reply with the single word ok"'    # needs the API key; proves the env file reaches ssh commands
```

## 5. Joint checkpoints (Mac and as1 together)

| Check | Expect |
|---|---|
| `mac$ mosh as1` | lands in tmux `main`; survives Wi-Fi off and on |
| Cmd+Shift+A in WezTerm | new tab on as1 |
| tmux copy mode (Ctrl+B `[`, Space, Enter), then `mac$ pbpaste` | the copied text |
| Cmd+Shift+Ctrl+4, then Cmd+V in `claude` on as1 | `[Image #1]` in the prompt |
| Cmd+V of text into a shell on as1 | pastes at once; `ls -l ~/.clip/latest` timestamp unchanged |
| `mac$ ssh as1 'echo $TMUX'` | empty line |

Clipboard bridge checks from the Mac (take a screenshot first):
```
mac$ clip-push && ssh as1 'file ~/.clip/latest'     # image/png, then PNG image data
mac$ time clip-push                                 # well under 1 s on the second run
mac$ clip-push --clear && ssh as1 'ls ~/.clip'      # nothing listed
```

If image paste fails: `mac$ clip-push` in a local terminal prints the ssh error;
`as1$ CLIP_BRIDGE_DEBUG=1 xclip -selection clipboard -t TARGETS -o` shows the shim's decision.

## Second Mac and rebuilds

- Second Mac: section 2 only, with the same `.env`, then the checkpoints. Nothing on the host is per-Mac.
- Host reinstalled: section 1, then on each Mac `ssh-keygen -R as1; ssh-keygen -R 192.168.10.2` (the address and
  LAN address from `.env`; the script prints the exact command) and re-run `./install-mac.sh`, then sections 3 and 4.
- Different host name, login or LAN: nothing to edit in the repo. On the host, `hostname`, the login and the
  network decide; on the Mac, `.env` does.
- Config change in the repo: `git pull` and re-run `./install-as1.sh --no-tools` or `./install-mac.sh`. Phase 1
  skips every step that is already in place and asks for `sudo` only if, say, `config/sshd` changed.
  Symlinked configs pick up the change without a re-run.

## Rollback (Mac)

- Clipboard push: `rm ~/.local/bin/clip-push`, delete the `Host as1-clip` block from `~/.ssh/config` (inside the
  `agentic-framework:agent-host` markers), reload WezTerm. On the host: `rm ~/.local/bin/clip-put ~/.local/bin/xclip && rm -rf ~/.clip`.
- WezTerm include: delete the `require("wezterm-agent-host")` line from `wezterm.lua`, or restore `wezterm.lua.before-agent-host`
  (or the older `wezterm.lua.before-as1`) if the script edited it; `rm ~/.config/wezterm/wezterm-agent-host.lua`.
- ssh config: delete the block between the `agentic-framework:agent-host` markers; PATH: the `agentic-framework:path` block in `~/.zshrc`.
- Old pull design (the host SSHing into the Mac), if `install-mac.sh` reports its leftovers: `sudo systemsetup -setremotelogin off`,
  `sudo rm /etc/ssh/sshd_config.d/100-tailnet.conf /usr/local/bin/clip-client`, remove the `kyle@as1` line from
  `~/.ssh/authorized_keys`. On the host, `install-as1.sh` already removes the old `Host macbook mini` block from `~/.ssh/config`.
