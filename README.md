# agentic-framework

Source of truth for `as1`, a headless Ubuntu box on a Tailscale tailnet that runs coding agents
(Claude Code, OpenCode, Oh My Pi), and for the Macs that reach it from WezTerm over SSH or mosh.
Three idempotent scripts do all the configuration; configs on as1 are symlinks into this checkout,
so edit here, never the installed copy.

| Script | Runs on | As | Does |
|---|---|---|---|
| `install-as1-root.sh` | as1 | root (`sudo`) | sshd hardening, ufw, apt packages, zsh as login shell, linger, Tailscale auto-update |
| `install-as1.sh` | as1 | `kyle` | symlinked configs, secrets file skeleton, `xclip` shim, oh-my-zsh, mise toolchains, uv, the three harnesses |
| `install-mac.sh` | Mac | you, no sudo | mosh, pngpaste, `~/.ssh/config` block, SSH key and key login to as1, WezTerm include, `clip-push` |

Order: as1 prerequisites, then the Mac script (it puts the Mac key on as1), then the as1 root script,
then the as1 user script, then one-time logins, then the joint checkpoints. Keep a key-based SSH session
open while the root script runs; it reloads sshd.

Conventions: `as1$` is a shell on as1, `mac$` a local shell on the Mac. The repo hardcodes one owner and
one network. For a different user, host or LAN, change these in one commit before running anything:

| Value | Current | Where it lives |
|---|---|---|
| as1 login | `kyle` | `config/sshd/10-hardening.conf` (`AllowUsers`), `config/ssh_config.mac`, `config/wezterm-as1.lua`, `install-as1-root.sh` (default when not run via sudo) |
| as1 hostname (MagicDNS) | `as1`, `as1.manee-goby.ts.net` | `config/ssh_config.mac`, `config/wezterm-as1.lua`, this README |
| as1 LAN address, LAN range | `192.168.10.2`, `192.168.10.0/24` | `config/ssh_config.mac` (`Host as1-lan`), `config/ufw.sh` |
| Macs | `macbook`, `mini` | docs only; nothing on as1 knows the Mac names |
| Repo | `github.com/kylenguyen/agentic-framework` | clone commands in this README |
| Mac key | `~/.ssh/id_ed25519`, no passphrase | `config/ssh_config.mac`; generated by `install-mac.sh` if absent |

## 1. as1 prerequisites (console, once)

Manual on purpose, so a script re-run can never lock you out.

1. Install Ubuntu Server LTS. Hostname `as1`, user `kyle` with a real password, tick "Install OpenSSH server".
   Importing a GitHub SSH identity is optional; it turns password login off until the root script runs,
   so a Mac with a new key must then have its key pasted at the console instead of `ssh-copy-id`.
2. Fixed LAN address `192.168.10.2` (DHCP reservation on the router).
3. Base packages, Tailscale, repo clone:
   ```
   as1$ sudo apt update && sudo apt full-upgrade -y && sudo apt install -y git curl
   as1$ curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up     # open the URL on a signed-in device
   as1$ mkdir -p ~/workspace && git clone https://github.com/kylenguyen/agentic-framework.git ~/workspace/agentic-framework
   ```
   In the Tailscale admin console: MagicDNS on, and "Disable key expiry" for as1. For a private repo,
   `sudo apt install -y gh && gh auth login` before the clone.

Verify:
```
as1$ hostname; systemctl is-active ssh tailscaled           # as1, active, active
as1$ tailscale ip -4                                         # 100.x.y.z
as1$ passwd -S kyle | awk '{print $2}'                       # P (a password is set)
as1$ sudo sshd -T | grep -i ^passwordauthentication          # yes, unless a GitHub key was imported
as1$ ls ~/workspace/agentic-framework/install-as1.sh
```

## 2. Mac client

Prerequisites, manual: FileVault on (the SSH key has no passphrase), Homebrew, WezTerm
(`brew install --cask wezterm`), and the Tailscale app signed in to the same tailnet with
"Start Tailscale on login" ticked and Tailscale DNS on.

```
mac$ mkdir -p ~/workspace && git clone https://github.com/kylenguyen/agentic-framework.git ~/workspace/agentic-framework
mac$ cd ~/workspace/agentic-framework && ./install-mac.sh
```

Run it in a terminal, not from a pipe. It installs mosh and pngpaste, writes the `as1`, `as1-lan` and
`as1-clip` blocks into `~/.ssh/config`, generates `~/.ssh/id_ed25519` if absent, installs the WezTerm include
(writes a minimal `wezterm.lua` if you have none, otherwise prints the one line to add), installs `clip-push`,
puts `~/.local/bin` on PATH via `~/.zshrc`, and finally makes `ssh as1` log in by key with no prompt. On
first contact it stores as1's host key; if as1 trusts no local key it runs `ssh-copy-id` and asks for kyle's
password once. It ends with `ok   ssh as1 logs in by key`.

It exits 1, with the command to run, when: as1 is unreachable (check Tailscale); a stored host key no longer
matches after a reinstall (`ssh-keygen -R as1; ssh-keygen -R 192.168.10.2`); or password login is off and no
key is trusted (paste `~/.ssh/id_ed25519.pub` into `~/.ssh/authorized_keys` on as1 at the console). Fix and re-run.

Then open a new shell and reload WezTerm with Cmd+Shift+R.

Verify (Mac alone):
```
mac$ ssh -G as1 | grep -E '^(hostname|user|identityfile) '                  # as1, kyle, ~/.ssh/id_ed25519
mac$ ssh -G as1-clip | grep -E '^(batchmode|controlmaster|connecttimeout) ' # yes, auto, 3
mac$ /Applications/Tailscale.app/Contents/MacOS/Tailscale status | grep as1 # listed, not offline
mac$ grep -c wezterm-as1 ~/.config/wezterm/wezterm.lua                      # 1
mac$ command -v clip-push && mosh --version | head -1                       # ~/.local/bin/clip-push
mac$ ssh as1 true && echo key-login-ok                                      # no prompt
```

## 3. as1 root script

```
mac$ ssh as1
as1$ cd ~/workspace/agentic-framework && sudo bash install-as1-root.sh
```

Refuses to run unless `kyle` has a password. Installs `config/sshd/10-hardening.conf` (key or password for
`kyle` only, no root, no empty passwords) and reloads sshd; installs tmux, mosh, gh, zsh, git, curl, file, jq,
unattended-upgrades; sets zsh as the login shell; applies `config/ufw.sh` (inbound only on `tailscale0`, plus
SSH from the LAN); enables linger; turns on Tailscale auto-update.

Verify, from the open session and a new one:
```
as1$ sudo sshd -T | grep -iE '^(passwordauthentication|permitrootlogin|allowusers) '   # yes, no, kyle
as1$ sudo ufw status verbose | grep -E 'Status|tailscale0|192.168.10'
as1$ loginctl show-user kyle | grep Linger                                             # Linger=yes
as1$ getent passwd kyle | cut -d: -f7                                                  # /usr/bin/zsh
mac$ ssh as1 true && echo still-ok
mac$ ssh -o PreferredAuthentications=password -o PubkeyAuthentication=no kyle@as1 true && echo password-ok
```

## 4. as1 user script

```
as1$ cd ~/workspace/agentic-framework && ./install-as1.sh        # --no-tools skips network installs
```

Symlinks `~/.tmux.conf`, `~/.zshenv`, `~/.zshrc`, `~/.bashrc.d`, `~/.claude/settings.json`,
`~/.claude/statusline-command.sh`, `~/workspace/CLAUDE.md` and `~/workspace/AGENTS.md` into the repo; creates
`~/.config/agents/env` from `env.example` (mode 600); installs the `xclip` shim and `clip-put`; with network,
installs oh-my-zsh, mise with Node, Bun and Python 3.12, uv, OpenCode, Oh My Pi and Claude Code.

Log out and back in. The new login lands in zsh inside tmux session `main`. If an older `main` session still
runs bash: `tmux kill-server`, log in again.

Verify:
```
as1$ echo $ZSH_THEME $TMUX | cut -c1-40           # robbyrussell /tmp/tmux-...
as1$ for c in mise node bun python3.12 uv claude opencode omp; do printf '%-10s %s\n' $c "$(command -v $c || echo MISSING)"; done
as1$ command -v xclip                             # ~/.local/bin/xclip, not /usr/bin
as1$ stat -c '%a' ~/.config/agents/env            # 600
as1$ readlink ~/workspace/AGENTS.md               # .../config/workspace/CLAUDE.md
mac$ ssh as1 'echo tmux=$TMUX; command -v mise'   # tmux= (empty), then a mise path
```

## 5. One-time logins and secrets (as1, manual)

Both logins print a URL and a code; open the URL in the Mac's browser.

1. Claude Code: `as1$ claude`, sign in, `/exit`. Or put `ANTHROPIC_API_KEY` in the secrets file; that is what
   `claude --bare` and non-interactive use need.
2. GitHub: `as1$ gh auth login` (GitHub.com, HTTPS, browser). Keep the repo remote on HTTPS.
3. Secrets: `as1$ $EDITOR ~/.config/agents/env`. Sourced by every shell, including `ssh as1 <cmd>`. Claude Code
   is denied read access to it by `config/claude-settings.json`.

Verify:
```
as1$ gh auth status
as1$ claude -p 'reply with the single word ok'
mac$ ssh as1 'claude --bare -p "reply with the single word ok"'    # needs the API key; proves the env file reaches ssh commands
```

## 6. Joint checkpoints (Mac and as1 together)

| Check | Expect |
|---|---|
| `mac$ mosh as1` | lands in tmux `main`; survives Wi-Fi off and on |
| Cmd+Shift+A in WezTerm | new tab on as1 |
| tmux copy mode (Ctrl+B `[`, Space, Enter), then `mac$ pbpaste` | the copied text |
| Cmd+Shift+Ctrl+4, then Cmd+V in `claude` on as1 | `[Image #1]` in the prompt |
| Cmd+V of text into a shell on as1 | pastes at once; `ls -l ~/.clip/latest` timestamp unchanged |
| `mac$ ssh as1 'echo $TMUX'` | empty line |

Clipboard bridge checks from the Mac (take a screenshot first):
```
mac$ clip-push && ssh as1 'file ~/.clip/latest'     # image/png, then PNG image data
mac$ time clip-push                                 # well under 1 s on the second run
mac$ clip-push --clear && ssh as1 'ls ~/.clip'      # nothing listed
```

If image paste fails: `mac$ clip-push` in a local terminal prints the ssh error;
`as1$ CLIP_BRIDGE_DEBUG=1 xclip -selection clipboard -t TARGETS -o` shows the shim's decision.

## Second Mac and rebuilds

- Second Mac: section 2 only, then the checkpoints. Nothing on as1 is per-Mac.
- as1 reinstalled: section 1, then on each Mac `ssh-keygen -R as1; ssh-keygen -R 192.168.10.2` and
  re-run `./install-mac.sh`, then sections 3 to 5.
- Config change in the repo: `git pull` and re-run `./install-as1.sh --no-tools` or `./install-mac.sh`.
  Symlinked configs pick up the change without a re-run.

## Rollback (Mac)

- Clipboard push: `rm ~/.local/bin/clip-push`, delete the `Host as1-clip` block from `~/.ssh/config` (inside the
  `agentic-framework:as1` markers), reload WezTerm. On as1: `rm ~/.local/bin/clip-put ~/.local/bin/xclip && rm -rf ~/.clip`.
- WezTerm include: delete the `require("wezterm-as1")` line from `wezterm.lua`.
- ssh config: delete the block between the `agentic-framework:as1` markers; PATH: the `agentic-framework:path` block in `~/.zshrc`.
- Old pull design (as1 SSHing into the Mac), if `install-mac.sh` reports its leftovers: `sudo systemsetup -setremotelogin off`,
  `sudo rm /etc/ssh/sshd_config.d/100-tailnet.conf /usr/local/bin/clip-client`, remove the `kyle@as1` line from
  `~/.ssh/authorized_keys`. On as1, `install-as1.sh` already removes the old `Host macbook mini` block from `~/.ssh/config`.
